# Копия заказа и возврат отменённого

## Что сделано

### Копия заказа

- Кнопка **«Копировать»** в модалке просмотра заказа и на странице `/admin/orders/[id]`
- Открывает форму создания с предзаполнением: `/admin/orders/create?from={id}`
- Новый ID появляется только после сохранения
- Не копируются shipment / veter-поля
- Если по позиции нет склада/офера (или исходный канал недоступен) — строка подсвечена

### Возврат отменённого

- Статус нельзя менять **только** у `done` / `completed`
- У `cancelled` можно сменить статус (с confirm) и снова править состав
- При возврате проверяются склад/офер (подсветка) и скидочная карта (баннер, если неактивна)

---

## Как протестить в браузере

### Копия

1. Админка → Заказы → открыть любой заказ (модалка или страница просмотра)
2. Нажать **«Копировать»**
3. Проверить: форма «Копия заказа #…», данные клиента/доставки/товары/карта на месте, без ID отправки
4. Если какая-то позиция без склада/офера — янтарная подсветка и текст причины
5. Сохранить → новый номер заказа в списке

### Возврат отменённого

1. Найти заказ со статусом **Отменён** (фильтр / показать скрытые)
2. Сменить статус на активный (например «Новый») → confirm «Вернуть…»
3. Заказ снова активен; в edit — состав редактируется
4. Если товара нет на складе/офере — подсветка строки
5. Если скидочная карта заказа неактивна — красный баннер у блока товаров/карты

### Выполненный (контроль)

1. Заказ **Выполнен** → dropdown статуса заблокирован (таблица, просмотр, edit)
2. Состав в edit недоступен для изменения

### Регрессия

1. Обычное создание заказа без `?from=` работает как раньше
2. Смена статусов у активных заказов (new → confirmed → …) без лишних confirm, кроме перехода в Выполнен/Отменён
